## 📁 Folder Guide

| Folder | Description |
|---|---|

## 📝 Honesty Notes

- Execution dates are recorded in the current Test Execution workbook. Evidence references are linked to all 99 test cases; some are supporting references and are qualified in Execution Notes.
- Some observations have unclear expected rules and are not confirmed defects.
- RTM mappings are a portfolio-level working baseline, not independently audited traceability.
- Responsive check used Chrome DevTools emulation, not a physical phone.
- Newsletter / Email a Friend confirmations do not prove inbox delivery.
- No real payment, API, database, automation, load or security testing was performed.
- Before public sharing, inspect and redact personal email addresses, names, account details and order identifiers visible in screenshots and documents.
